=== The parameter schema pi advertises to the model ===
expectedUpdatedAt: {
  "type": "string",
  "description": "The target Project Goal's exact updatedAt from the caller's last read, for project start, update, set_active, complete, reopen, archive, and delete. A stale value returns a typed conflict instead of overwriting a newer change."
}
required: ["scope","action"]

=== A model reads the goal, then claims it against the timestamp it read ===
> worklist {"scope":"project","action":"add","title":"Guarded dispatch"}
  ok: {"id":"guarded-dispatch","title":"Guarded dispatch","status":"open","createdAt":"2026-08-13T06:40:04.991Z","updatedAt":"2026-08-13T06:40:04.991Z"}
