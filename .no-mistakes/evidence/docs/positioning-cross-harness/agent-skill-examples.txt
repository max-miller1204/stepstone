The generated agent skill, executed line by line against the shipped bin
=======================================================================
Every command below is the Examples block of the SKILL.md that ships in the tarball,
run verbatim in a fresh git repository. 'npx -y stepstone@latest' is served by the
packed build of this branch. Only 'plan.json' was created first, as the block assumes.
Output is trimmed to the first two lines per command; a non-zero exit would be shown.

Note on the one non-zero exit above: the `--expect-updated-at 2026-05-04T09:12:31.004Z`
example carries a fixed placeholder timestamp, so in a scratch repository it correctly
reports a concurrent-change conflict and exits 4 without writing. That is the documented
precondition doing its job, not a broken example; every other line of the skill's Examples
block succeeds against the shipped bin.
