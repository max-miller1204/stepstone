docs/pi.md 'Using the service from another extension', exercised from a consumer package
======================================================================================
The consumer is an empty package that ran 'npm install stepstone-0.2.0.tgz' and nothing
else; it imports the documented ./src/* subpath export and drives the same goal file the
README quickstart just created. The host is TypeScript-aware (tsx here, Pi in the
documented case), because the export is TypeScript source; plain 'node' refuses to strip
types under node_modules.
