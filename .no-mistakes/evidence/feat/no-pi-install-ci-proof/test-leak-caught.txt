==============================================================

A real value import of @earendil-works/pi-tui is injected into
src/tui/style.ts, a file inside the module graph behind src/cli.ts, and then
reverted. Every command below was really run in this worktree.

typechecks clean, because this checkout installs every Pi peer as a
devDependency. Only the two new checks can see it.

 A lazy import the install job cannot reach, caught anyway
==============================================================

The static scan is the broader net, not just the faster one: an
`await import("@earendil-works/pi-tui")` inside a function that no command
calls never fails at runtime, so the pack-and-install job passes while the
tarball still ships an import that would break the moment that code path runs.
