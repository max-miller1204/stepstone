# Screenshot fonts

These font files are committed so image rendering does not use system fonts.
Do not download fonts during screenshot generation.
All fonts use the SIL Open Font License 1.1.

- `JetBrainsMono-Regular.ttf` and `JetBrainsMono-Bold.ttf`: [JetBrains Mono 2.304](https://github.com/JetBrains/JetBrainsMono/tree/v2.304/fonts/ttf). See `OFL.txt`.
- `NotoSansMath-Regular.ttf`: [Google Fonts](https://github.com/google/fonts/tree/main/ofl/notosansmath). See `NotoSansMath-OFL.txt`.

The renderer uses Noto Sans Math for `⇅`. It uses JetBrains Mono for the other terminal cells.
The committed font bytes and the npm shrinkwrap define the image rendering inputs.
